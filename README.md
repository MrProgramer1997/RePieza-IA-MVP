# RePieza IA MVP

Prototipo web interactivo para la exposición de RePieza IA.

## Demo
El MVP simula el flujo completo de una solicitud de repuesto:
1. El usuario describe el objeto y la pieza dañada.
2. Ingresa medidas y puede adjuntar una fotografía.
3. RePieza IA organiza requisitos y genera una propuesta paramétrica.
4. La interfaz presenta un modelo 3D conceptual, material sugerido, medidas, tiempo y cotización.
5. El diseño pasa a revisión técnica antes de fabricación.
6. Se puede exportar un STL demostrativo.

Caso precargado: acople/engranaje de una licuadora doméstica.

> Este prototipo demuestra el flujo del producto. No reemplaza la validación dimensional ni la revisión técnica antes de fabricar una pieza real.
